# Code of Conduct

## Our standard

This project is a place for focused technical collaboration. Participants are
expected to:

- discuss ideas and code without personal attacks;
- give reproducible evidence for bug reports;
- respect privacy and never publish another person's tokens, cookies, logs, or
  device identifiers;
- accept maintenance decisions without harassment.

Harassment, discrimination, doxxing, deliberate disruption, and disclosure of
private security information are not acceptable.

## Enforcement

Maintainers may edit or remove content and may temporarily or permanently block
participants whose behavior harms the project or its contributors.

For a confidential conduct report, use the repository's private security
advisory contact rather than a public issue.
